# Time Zone

A simple Python application that allows users to check the current time in different locations around the world.

## Features

* Check the current time in different locations
* Work with different time zones
* Display local time based on the selected location

## Tech Stack

* Python

## How It Works

The application uses Python's time and time zone functionality to determine and display the current local time for different locations.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Quadri702/Time-zone.git
cd Time-zone
```

### Run the project

```bash
python main.py
```
